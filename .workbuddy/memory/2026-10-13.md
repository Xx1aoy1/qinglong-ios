## 日志查看「突然就没了」的根因与修复（待推送）

用户录屏：实时日志看几秒后内容整体消失，只剩「暂无日志内容」，顶部仍是「运行中 · 2 KB」。

### 根因（对照 whyour/qinglong 后端源码核实）

- 后端 `back/shared/logReader.ts`：`truncated: offset > 0 || nextOffset < total`，语义是**「本次分片未覆盖整个文件」**。
- 客户端增量轮询追平文件末尾后（offset == total == 2048），`offset > 0` 恒成立 → `truncated` 恒为 `true`。
- 前端 `LogConsoleView.fetchIncrement` 误把 `truncated == true` 当作「日志被轮转」，直接 `text = chunk.content`（空）→ 内容被清空。时间线与录屏吻合（轮询间隔 3s）。

### 修复

- 删除 `truncated` 分支；改为只在**文件比已读位置还小**（`chunk.total < nextOffset`，真正的轮转/清空）时静默重取尾部：`fetch(nil, chunkSize, true)`。
- 影响面：任务日志 / 订阅日志 / 面板日志（共用 LogConsoleView）。
- 顺带 `project.yml` 版本号升至 1.0.4，待推送后打 `v1.0.4` tag 发布。
