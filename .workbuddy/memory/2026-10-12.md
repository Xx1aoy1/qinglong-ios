### 重要经验
- **工具输出渲染层会把 `String` 显示成 `Vfjxct` 之类的假字符串**。判断源码问题时必须以字节级读取（`open(p,'rb')` + 码点检查）为准，不要根据显示内容改代码 —— 曾差点误改一堆正确的 `String`。
- `git add -A` 会把本地临时脚本（含 token）一起提交 → GitHub push protection 直接拒绝推送（GH013）。临时脚本一律放仓库外（%TEMP%），`.gitignore` 已加 `.ci_logs.txt/.jobs.json/.runs.json/.poll_ci.sh`；发现后用 `reflog expire + gc --prune=now` 清掉悬空对象，并验证 `ghp_` 零残留。
- CI 并发组 `ipa-${{ github.ref }}` + `cancel-in-progress` → 构建进行中再 push 会取消当前构建，要等上一轮结束再推。
