## 新增「配置文件」与「任务视图」两块功能（v1.0.5）

用户反馈 IPA 里找不到「配置文件」，另要求定时任务加「创建视图 / 视图管理」。

### 1) 配置文件（面板左侧菜单同名功能）

后端接口（`back/api/config.ts` 对照）：

| 用途 | 接口 |
| --- | --- |
| 文件清单 | `GET /api/configs/files` → `[{title, value}]`（已过滤 blackFileList）|
| 读取内容 | `GET /api/configs/detail?path=config.sh` → `{code,data:"<内容>"}` |
| 保存 | `POST /api/configs/save` `{name, content}` |

- 注意 `/api/config/file` 与 `GET /api/configs/:file` 已下线（返回 410），只能用上面三个。
- 客户端：`QLConfigFile` / `ConfigService` / `ConfigFilesView`（列表 + 内嵌 TextEditor 编辑器，
  支持复制、导出到「文件」、重新读取；未保存时标题显示「保存*」）。
- 入口放了两处：**更多 → 面板配置 → 配置文件**，以及**概览页快捷操作**（避免再次"找不到"）。
- 常见文件名带用途说明：config.sh（通知/HACK/镜像）、extra.sh、task_before.sh、task_after.sh 等。

### 2) 任务视图（面板标签页）

后端（`back/api/cron.ts` + `back/data/cronView.ts` + `services/cronView.ts`）：

| 用途 | 接口 |
| --- | --- |
| 列表 | `GET /api/crons/views` |
| 新建 / 更新 | `POST` / `PUT /api/crons/views`（Joi 只收 name、sorts、filters、filterRelation；更新必须带 id）|
| 删除 | `DELETE /api/crons/views`，body 是 `[id, ...]` |
| 启停 | `PUT /api/crons/views/enable|disable`，body `[id]` |
| 排序 | `PUT /api/crons/views/move` `{id, fromIndex, toIndex}` |

视图结构：`{id, name, position, isDisabled, type, filters, sorts, filterRelation}`

- `filters`: `[{property, operation, value}]`，property ∈ command/name/schedule/status/labels/sub_id，
  operation ∈ Reg(包含)/NotReg(不包含)/In(属于)/Nin(不属于)；status 与 sub_id 只能 In/Nin 且 value 为数组。
- `sorts`: `[{type: 'ASC'|'DESC', value: 'name'|...}]`（注意字段名是 `value`，不是 property）。
- `type == 1` 是面板内置视图（默认名「全部任务」），不可改名 / 删除，只能停用；停用后至少保留一个启用视图。
- 面板真实查询是 `GET /api/crons?queryString=<JSON.stringify({filters,sorts,filterRelation})>`；
  **客户端没有用这个参数**，而是拉到全量任务后本地按同一套语义求值（`QLCron.matches` / `applying`），
  这样切视图不重新请求、不破坏列表缓存，且状态胶囊的计数自动收敛到当前视图范围内。
- 校验过：后端 `Reg` 实际是 `LIKE %value%`（还会额外拼一次 `encodeURI(value)`），
  所以本地用「不区分大小写的 contains」等价；`Nin` 在 status 上还要排除 isDisabled，客户端用
  `statusValue`（isDisabled=1 → 2）统一处理。

### 体验 / 性能约定（新增）

- 列表页出现「多行筛选栏」时，每行单独抽成计算属性（`viewTabsRow` / `statusRow` / `labelsRow`），
  避免单个 ViewBuilder 表达式过长导致类型检查爆炸与重绘变慢。
- 切换筛选条件只改本地状态，不触发网络请求。
